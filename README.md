# superstore-sales-dashboard-excel
Interactive Excel sales dashboard using Pivot Tables, Pivot Charts and Slicers
**Tools:** Excel, Pivot Tables, Pivot Charts, Slicers
**KPIs:** Total sales, total profit, profit margin, total quantity

**Key insights**
- Technology contributes 51% of total profit (Furniture only 6%)
- Tables, Bookcases and Supplies are loss-making sub-categories
- Sales peak in September to December, with November the highest
- Year-wise sales grew from 484K in 2014 to 733K in 2017 (about 51%)

**File:** salesdata report.xlsx
